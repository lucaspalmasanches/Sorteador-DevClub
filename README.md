# Sorteador de Números Responsivo 🎲✨

![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)

## Sobre o Projeto ✨

Este projeto, inicialmente desenvolvido a partir de uma aula introdutória de JavaScript do [DevClub](https://www.devclub.com.br/), foi **totalmente aprimorado e expandido** para se tornar um "Sorteador de Números" interativo e robusto. Indo **muito além do proposto na aula**, o projeto agora conta com **total responsividade** (desktop, tablet e mobile), uma interface de usuário aprimorada e lógica JavaScript sofisticada.

Minhas principais contribuições incluem a **validação de entradas** para garantir números inteiros e válidos, a exibição de resultados e mensagens de erro dinâmicas diretamente na interface (substituindo o básico `alert`), e a utilização de `setTimeout` para gerenciar a visibilidade dessas mensagens de erro, proporcionando uma experiência de usuário fluida e intuitiva.

Com este projeto, demonstro não apenas os fundamentos da lógica de programação e manipulação do DOM, mas também a capacidade de aprimorar a usabilidade, implementar validações robustas e criar designs adaptáveis, refletindo um forte foco na experiência do usuário e na qualidade do código.

## ✨ Funcionalidades

*   **Design Totalmente Responsivo:** Layout que se adapta de forma fluida e elegante para visualização em **desktops, tablets e smartphones**, oferecendo uma experiência de usuário consistente e otimizada.

*   **Entrada de Usuário Aprimorada:** Permite que o usuário defina um valor mínimo e um valor máximo para o sorteio.

*   **Validação de Entradas:** Garante que os valores inseridos sejam números inteiros e maiores que 0, com feedback visual para o usuário.

*   **Geração de Número Aleatório:** Gera um número pseudoaleatório dentro do intervalo especificado.

*   **Exibição Dinâmica do Resultado:** Apresenta o número sorteado diretamente em um parágrafo na interface.

*   **Mensagens de Erro Temporizadas:** Exibe mensagens de erro claras e que desaparecem automaticamente após 3 segundos, utilizando `setTimeout`.

*   **Interação por Botão:** Um botão simples para disparar a ação de sorteio.

*   **Interface Intuitiva:** Design direto e fácil de usar, com foco na experiência do usuário.

## 📚 Aprendizados

Este projeto foi uma experiência valiosa para consolidar e expandir meus conhecimentos em:

*   **Desenvolvimento Responsivo:** Implementação de um layout que se adapta perfeitamente a diferentes dispositivos (desktop, tablet e mobile), **indo muito além do escopo inicial da aula**.

*   **JavaScript Avançado e Lógica de Programação:** Aprimoramento da lógica para geração de números aleatórios, validação de entradas (inteiros, números positivos) e manipulação condicional.

*   **Manipulação de DOM Aprofundada:** Captura de elementos, leitura de valores, atualização dinâmica de conteúdo (parágrafos para resultados e mensagens de erro), e controle de visibilidade.

*   **User Experience (UX) e Feedback Visual:** Implementação de feedback claro ao usuário através de mensagens de erro dinâmicas e resultados exibidos na tela.

*   **Funções de Temporização:** Utilização de `setTimeout` para criar interações com tempo controlado (mensagens de erro que desaparecem automaticamente).

*   **Depuração e Correção de Bugs:** Habilidade aprimorada na identificação e resolução de problemas no JavaScript, garantindo a robustez da aplicação.

*   **HTML Semântico e CSS Otimizado:** Estruturação clara do conteúdo web e estilização adaptável para uma interface de usuário agradável e funcional.

*   **Controle de Versão:** Gerenciamento eficiente de código com Git e GitHub.
